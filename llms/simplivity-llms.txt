# SimpliVity (HPE OmniStack REST API)

> SimpliVity is the hyperconverged infrastructure (HCI) pioneer acquired by Hewlett Packard Enterprise in 2017 and shipped as HPE SimpliVity. Its OmniStack data virtualization platform delivers built-in deduplication, compression, backup, replication, and disaster recovery for VMware and Hyper-V clusters. The programmatic surface is the HPE OmniStack REST API (v1.25), served on-appliance by the Management Virtual Appliance (MVA) and authenticated with an OAuth2 password grant issuing read/write bearer tokens.

## APIs

- [HPE OmniStack REST API (Swagger)](https://github.com/HewlettPackard/hpe-simplivity-swagger): 87 operations across backups, virtual_machines, datastores, hosts, omnistack_clusters, cluster_groups, policies, external_stores, security (certificates/roles), and tasks.

## Auth & conventions

- [Authentication profile](authentication/simplivity-authentication.yml): OAuth2 password grant, token endpoint /api/oauth/token, Authorization: Bearer, read/write scopes, TLS 1.2+, tokens expire after 10 min inactivity / 24 h.
- [OAuth scopes](scopes/simplivity-scopes.yml)
- [Conventions](conventions/simplivity-conventions.yml): offset/limit pagination, task-polling async model (202 + TaskMO, getTask), no idempotency-key mechanism.
- [Error catalog](errors/simplivity-problem-types.yml): standard HTTP status codes; per-task failures in TaskMO.
- [Lifecycle](lifecycle/simplivity-lifecycle.yml): spec version 1.25; 3 deprecated operations flagged.
